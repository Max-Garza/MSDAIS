1. Zero Mean Error - The mean of residuals is close to zero. Can be determined with a scatterplot of the residuals and the predictions (y and x respectively)
2. Homoscedasticity - Residual variance is in a constant range over x values. Heteroscedasticity suggests the opposite. Can be checked using a Breusch-Pagan test. p-value > 0.05
3. Independence - Residuals are not autocorrelated. Can be checked using a Durbin-Watson test. p-value > 0.05
4. Normality - The residuals should be normally distributed. Can be checked using a Shapiro-Wilk test. p-value 0.05

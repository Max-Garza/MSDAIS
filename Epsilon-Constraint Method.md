* Select one objective function and represent the other objective function(s) as (a) constraint(s), where the right-hand side is a massive number
* Solve the new model. If this results in an infeasible model, then no solutions are possible. If there is one optimal solution, then the next steps need to be done only once. If there are multiple optimal solutions, then the next steps must be done for each solution.
* Select the other objective function and represent the original objective function as a constraint, where the right-hand side is the optimal value generated earlier
* The solution generated is Pareto efficient.
This generates an entire set of Pareto efficient solutions, which can be limited to a Pareto front.
